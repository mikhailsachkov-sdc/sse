# SSE TASK 2: BUILD A FUNCTION GRAPH

Select one system and one meaningful function. Build a small graph that separates the behavior type from actual execution and effect.

1) **Define the Function**  carrier role · action · target role · EffectSpecification
2) **Specify the expected manifestation**  parameter + change or preservation + target/desired state
3) **Define one FunctionRealization**  implementing SystemComponent / configuration
4) **Describe one FunctionExecution**  actual carrier · target · context/time
5) **Record FunctionEffect + EffectManifestation**  include Initial/Final state OR Desired state + TimeInterval
6) **Evaluate the result**  compare with EffectSpecification; identify a defect if present
